## why git makes development easier:
git is important in modern software engineering for many reasons:

1- safeguarding code: every commit creates a historical checkpoit, allow developers to revert changes or to restore previous work.
2- Tracking history: you can track all changes with all details.
3- enabling team collaboration: git enables multiple team member to work on the same codebase using isolated branches.
